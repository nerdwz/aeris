# AERIS

Aplicativo mobile-first para registro e acompanhamento de treinos pessoais. Construído com HTML, CSS e JavaScript puro.

## Status
🚧 Em desenvolvimento

## Funcionalidades previstas
- [ ] Registro de treinos e exercícios
- [ ] Monitoramento de streak diário
- [ ] Progressão de cargas e recordes pessoais
- [ ] Acompanhamento de composição corporal
- [ ] Frases motivacionais diárias
- [ ] Navegação entre páginas (Home, Treino, Progresso, Perfil)

## Tecnologias
- HTML5 semântico
- CSS3 com variáveis e tokens de design
- JavaScript vanilla
- Fontes: Gloock + Figtree (Google Fonts)
- Ícones: Tabler Icons

## Como rodar
Abra o `index.html` com Live Server no VS Code ou qualquer servidor local.
